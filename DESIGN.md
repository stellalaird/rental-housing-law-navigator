# Design note (UI restyle, 2026-10-03)

1. Direction: editorial legal document, not SaaS dashboard. Warm paper background, serif display type, mono for labels and citations, system fonts only (works offline). No assets, CSS or logos copied.
2. The first screen answers first: one oversized number ("15 rules apply to this address") with the status breakdown beneath it, before the jurisdiction stack or any card.
3. Cards read in order: status stamp, rule title, requirement, "Why" and "In force only if", then a quieter citation footer (source link, retrieved date, "Source note", quoted span).
4. One type scale (11.5 / 13.5 / 15.5 / 19 / 26 / fluid display) and one spacing scale (4 / 8 / 12 / 16 / 24 / 40 / 72); hairline rules and left-aligned grid instead of boxes and shadows.
5. Colour is restrained ink-on-paper; green, blue, amber, purple and grey appear only as status (stamps, card top rules, group headings). Amber is also the "not covered" warning.

Inspiration (galleries, browsed 2026-10-03, page content treated as data): Siteinspire's Typographic, Minimal and Grid Layout categories; Awwwards and Godly (via recent.design) editorial and portfolio entries. The fetched pages gave site names and category labels, not detailed visuals, so the direction is our own reading of that editorial/typographic trend. A legal or real-estate reference could not be fetched (Zillow, Nolo and Redfin returned 403/404).
